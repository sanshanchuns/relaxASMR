# 一、视频画面拆解

## 1.1 技术摘要

| 项 | 值 |
|----|-----|
| 分辨率 | 3840×2160（4K） |
| 时长 | 约 **1.50 s**（`loop_0.98` + `dur_3` + `fade_0.5` 拼接循环） |
| 编码 | H.264 |
| 文件名线索 | `loop_0.98` ≈ 0.98 s 段；`dur_3` = 3 段循环；`fade_0.5` = 0.5 s 交叉淡化 |

## 1.2 画面描述

雨后/雨中 **湖畔公园林间** 场景：

- **前景**：湿润草坪、多棵成熟阔叶乔木（叶面饱满、颜色深绿，明显带水）
- **中景**：树干深色饱和；右侧 **石板曲径**；低矮 **竹篱/木桩围栏**
- **背景**：透过树林可见 **平静湖面**（灰白水面），远处树线朦胧
- **天气**：阴天漫射光，背景略带雾气，**稳定、偏轻的中小雨**，非暴雨
- **风**：枝叶几乎无大幅摆动 → 听感应以 **垂直落雨** 为主，风感弱

**不是**：城市窗景、室内、帐篷、屋顶特写、竹林密植、暴雨雷电。

## 1.3 场景归类与标签

| 维度 | 归类 |
|------|------|
| **场景类型** | 自然 · 公园 · 湖畔林间（Park / Lakeside Woodland Rain） |
| **雨势** | 小雨～中雨（Light to Moderate），持续、均匀 |
| **空间感** | 近场草地/树叶 + 中景路径 + 远景湖面，需要 **纵深分层** |
| **情绪** | 清新、安静、略带孤独感的治愈绿（Green ASMR） |
| **视觉节奏** | 短循环、变化少 → 音频宜 **稳定底床 + 低密度事件**，不宜频繁突变 |

### 推荐场景标签（Rain · 睡眠向）

| 标签 | 匹配度 | 说明 |
|------|--------|------|
| 睡眠 / 长时陪伴 | ★★★★★ | 画面静、雨势稳、无刺激元素 |
| 湖畔雨天 | ★★★★★ | 背景湖面是画面锚点 |
| 森林雨 / 公园雨 | ★★★★☆ | 树木与草地为主 |
| 城市窗雨 | ★☆☆☆☆ | 无建筑、无窗户 |
| 雷雨 / 刺激向 | ★☆☆☆☆ | 无闪电、无狂风 |
| 专注 / 钢琴（Lake） | — | **属 Lake 系列，不在 Rain 套配方** |

# 三、七层配方（最终）

> 综合 **§一 画面** + **§二 原声** 输出 Reaper 配方。  
> 不必照搬原声：可在原声基础上 **创新、丰富细节**，但须 **逻辑合理**——阴天持续小雨时鸟类通常不叫，故 **不配鸟鸣**。  
> 成片使用 `assets/rain_sound` 分层叠床；视频轨 **-inf dB**，仅渲染。

### 七层定位（Rain 睡眠系列）

| 层 | 职责 | 本场景 |
|----|------|--------|
| 1_base | 空气底噪铺底 | 宽频空气感（非晴天微风） |
| 2_rain | 雨势主体 | 小雨主层 |
| 3_impact | 物理击打 · 真实感 | 稀疏雨打树叶 |
| 4_water | 水体 · 地点锚点 | **留白**（湖面远） |
| 5_env | 空间环境包络 | 林间雨 |
| 6_life | 生物事件 | **稀疏远处鸟鸣** |
| **7_comfort** | **心理舒适 · 画龙点睛** | **伞面水滴 loop**（无尖锐雨声） |

**7_comfort 心理舒适层** 是普通「下雨 ASMR」与 Rain 睡眠系列的 **分水岭**：营造 **安全感、包裹感**。本场景：机位伞上 → **仅伞面水滴击打**，与 2_rain 雨层分工，不叠「大雨伞下」类含尖锐雨声的素材。

对照设计文档：[`design/rain_series/rain_sound_design.md`](../../../design/rain_series/rain_sound_design.md)。

## 3.2 各层详解

### 1_base · 底噪层

| 推荐关键词 | 优先级 | 理由 |
|------------|--------|------|
| **空气底噪** | 主 | 雨天底床应是湿润空气/远场环境，非晴天「树叶微风」 |
| 雨天微风 | 低 | 画面枝叶几乎不动；若用须极弱且带雨感 |
| 晴天微风 / 落叶风 | **不推荐** | 听感像大树下晴天，与阴天小雨违和 |

**选用**：`空气底噪_河边湖边午后环境`（自 `4_water` 迁入 `1_base/空气底噪/`）· vol **0.28** · loop

---

### 2_rain · 雨层（主体）

| 推荐关键词 | 优先级 | 理由 |
|------------|--------|------|
| **小雨** | 主 | 叶面湿润、雨线细、天空灰白 |
| 毛毛雨 | 可选 | 若听感偏响可换更柔 drizzle |
| 大雨 / 暴雨 | 不推荐 | 与画面雨势不符 |

**选用**：`小雨` — 树叶淅沥 · vol **1.0** · loop · 占听感 **30–50%**

**长时包络**（Macro Dynamics）：

| 参数 | 值 | 说明 |
|------|-----|------|
| `shape` | `single_wave` | 整片 3h 一个正弦起伏 |
| `depth` | **0.08** | 两端约 −8%，中段回到基准 |
| `peak_at` | `center` | 中段雨势略强，模拟风/雨一阵 |

由 `asmr_apply_recipe` 写入轨 2 Volume 包络。

---

### 3_impact · 击打层

| 推荐关键词 | 优先级 | 理由 |
|------------|--------|------|
| **雨打树叶** | 主（scatter） | 树冠茂密、叶面挂水；物理真实感 |
| 雨打雨伞 | — | **已移至 7_comfort**（心理层，非物理击打主责） |
| 雨打窗户 / 屋顶 | 不推荐 | 无窗、无屋顶构图 |

**选用**：`雨打树叶` · vol **0.5** · scatter · gap **3–8 min** · random **0.6**

---

### 7_comfort · 心理舒适层（画龙点睛）

| 推荐关键词 | 优先级 | 心理功能 |
|------------|--------|----------|
| **伞面水滴 / 小雨击打伞** | 主 | 近场、柔软、被伞遮挡；**只要击打声，不要雨势** |
| 大雨伞下 / 伞下春雨 | **不推荐** | 常夹杂尖锐雨声，与 2_rain 重复且刺激 |
| 帐篷 / 屋檐庇护 | 备 | 其他场景可用 |

| 素材 | 模式 | 音量 | 说明 |
|------|------|------|------|
| `小雨击打雨伞.wav` | **loop** | **0.45** | 纯伞面水滴；雨势由轨 2 承担 |

**本场景叙事**：机位在伞下 → 舒适层只保留 **水滴打伞面** 的亲近感，尖锐雨声留给 `2_rain`。

---

### 4_water · 水体层

| 推荐关键词 | 优先级 | 理由 |
|------------|--------|------|
| **（留空）** | — | 湖面在画面 **远景**，树林遮挡，无近场拍岸/浪花 |
| 湖水 loop | 不推荐 | 近场水声会误听成底噪，且与 1_base 职能混淆 |

**选用**：**留白**

---

### 5_env · 环境层

| 推荐关键词 | 优先级 | 理由 |
|------------|--------|------|
| **森林 雨（纯雨）** | 主 | 林间空间包络；须 **无鸟叫、无蝉鸣** |
| 竹林 雨 | 低 | 右侧有竹篱但非主景，不宜竹叶声压过阔叶雨 |

**注意**：与 1_base、2_rain 易叠厚；**低音量**。原 5_env 素材含鸟叫，已替换为电影级森林雨。

**选用**：`电影级森林雨天气素材` · vol **0.22** · loop

---

### 6_life · 生物层

| 推荐关键词 | 优先级 | 理由 |
|------------|--------|------|
| **远处鸟鸣** | 主（scatter） | 长时雨声易单调；偶发 **远处** 单声打破沉闷，但不抢戏 |
| 连续鸟鸣 / 成群鸟叫 | 不推荐 | 像晴天公园，突兀且破坏睡眠感 |
| 蛙鸣 | 低 | 更适雨夜；本画面为日间灰天 |

**混音**：低音量、长间隔；雨天可偶发远处鸟叫，但须 **稀疏、远、短**。

**选用**：`api_mvi6918_bird_distant`（ElevenLabs AI 原声）· vol **0.3** · scatter · gap **12–28 min** · random **0.55** · 混响可在 Reaper 片段级按需加

## 3.3 工程操作

| 文件 | 说明 |
|------|------|
| `scripts/asmr_config.lua` | Reaper 配方数据（与本节 §3.1 同步） |
| `../../scripts/scenes/MVI_6918.lua` | 场景 canonical 副本 |
| `MVI_6918.rpp` | 生成：`python3 Reaper/scripts/generate_subproject.py --scene MVI_6918` |

打开工程后：

1. 运行 `asmr_apply_recipe.lua` — 铺轨 1–7 循环 + 稀疏 + **轨 2 音量包络**（**不改动轨 8 视频**）
2. 仅重刷包络：再次运行 `asmr_apply_recipe`（选「仅循环」）或配方里改 `vol_envelope` 后全量应用
3. **Group 总线**：轨 1–7 进 Folder，父轨 `Group` 上 **ReaEQ 削高频**（见 `rain_sound_design.md` §Group Bus）
4. 单轨稀疏：`asmr_scatter_track.lua` 输入 `3_impact` 或 `6_life`

**修订记录**：初版误套窗景；移除鸟鸣；伞下声迁至 7_comfort；**v3** 空气底噪入 1_base、4_water 留白、comfort 换 `小雨击打雨伞.wav`；**v4** 轨 2 长时单周期音量包络；**v5** Group 总线 EQ 规范。
