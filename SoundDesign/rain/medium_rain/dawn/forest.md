# 森林中雨 · 黎明

基准：[../night/forest.md](../night/forest.md)

---

## 黎明差异

- **EQ**：低通 ~13 kHz · 高通 ~38 Hz
- **L4**：晨鸟 sparse + 远虫 optional · 蛙关闭
- **无雷**

---

## L1 · Track 01 · 树叶

**ElevenLabs：**

```
Medium rainfall on broad forest tree leaves at dawn, continuous soft shushing patter, warm mellow tone, rich low-mid body, muffled smooth, not sharp, pre-sunrise soft grey light, seamless loop, no thunder no wind
```

## L1 · Track 02 · 树冠（可选）

**ElevenLabs：**

```
Medium rainfall on forest tree canopy at dawn, continuous muffled patter on upper branches, warm low-mid texture, not bright, pre-sunrise atmosphere, seamless loop, no thunder no wind
```

## L4 · 黎明生物

**晨鸟：**

```
Single early morning bird chirp at dawn, one soft call, 1 second, isolated, no chorus
```

**远虫（可选）：**

```
Single distant cricket chirp at dawn, one brief fading call, 1 second, isolated, very quiet
```
