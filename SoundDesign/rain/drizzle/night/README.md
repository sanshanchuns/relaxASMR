## 夜晚共用

- L1 **恒定细雨**，无 automation
- **无雷**（细雨专辑默认）
- **单一音效**：每轨 / 每 Prompt 一种声源（见 [../README.md](../README.md#单一音效原则)）
- 母带：高通 ~40 Hz · 低通 ~12 kHz · LUFS -18 ~ -16
- 反循环：仅 L3/L4 jitter + L2 异长（可选）
