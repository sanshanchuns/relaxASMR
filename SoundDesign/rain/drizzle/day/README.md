## 与夜晚 / 黄昏的核心差异

| 项目 | 夜晚 | 白天 |
|------|------|------|
| EQ | 低通 ~12 kHz | 中性，可至 ~16 kHz |
| L4 | 夜虫 | **极 sparse 远鸟**，无虫 chorus |
| L3 远雷 | 关闭 | 可选 · ≥45 min jitter · -26 dB |
| 氛围 | 睡眠 | 专注、阅读、背景 |

主轨仍 **恒定细雨**，无 automation。Prompt 遵守 [单一音效原则](../README.md#单一音效原则)。
