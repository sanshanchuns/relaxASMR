# 黄昏 · 场景索引 【P3】

时段：**蓝调 / 暮光**。基准 [../night/](../night/) · 规范 [../README.md](../README.md)

时段顺序：night P1 → dawn P2 → **dusk P3** → day P4

---

## 与夜晚的核心差异

| 项目 | 夜晚 | 黄昏 |
|------|------|------|
| EQ | 低通 ~12 kHz | 低通 ~14 kHz，略暖 |
| L4 | 夜虫 | 极偶远虫 + **极 sparse 远鸟**（归巢一声） |
| L3 | 同逻辑 | 同逻辑，略可略密 |
| 氛围 | 深暗 | 蓝调、过渡、仍静 |

主轨仍 **恒定细雨**，无 automation。Prompt 遵守 [单一音效原则](../README.md#单一音效原则)。
