## 制作优先级

### 时间（四时段）

| 优先级 | 时段 | 说明 |
|--------|------|------|
| **P1** | 夜晚 | 睡眠 · 8 h |
| **P2** | 黎明 | 破晓 · gentle wake · 3–8 h |
| **P3** | 黄昏 | 蓝调 · 放松 |
| **P4** | 白天 | 专注 · 背景 |

### 场景（每时段内）

森林 → 帐篷 → 木屋 → 溪流

### 推荐顺序（16 条 / 专辑 / 雨势）

```
night/×4 → dawn/×4 → dusk/×4 → day/×4
```

雨势专辑线：细雨 → 中雨 → 大雨（各 16 条，结构相同）

- **主轨恒定** · **固定听点** · **单一音效** · **反循环**（L3/L4 jitter）
