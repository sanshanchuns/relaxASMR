# 湖泊 · 专注 / 静心专辑线

与 [雨声专辑](../rain/medium_rain/README.md) 不同：本线以 **舒缓器乐（钢琴）为主轨**，自然声为副轨，面向 **工作、阅读、冥想**，非睡眠向。

---

## 定位

| 项目 | 雨声 ASMR | 湖泊 · 专注 |
|------|-----------|-------------|
| 主轨 | 雨 / 环境 loop（80%+） | **钢琴曲 loop（65–75%）** |
| 副轨 | 风、溪流、随机 one-shot | **划船、鸟鸣（高/低频分轨）** |
| 听感 | 掩蔽噪音、助眠 | **稳定节奏感、不抢注意力** |
| 目标 LUFS | Integrated **-18 ~ -16** | Integrated **-16 ~ -14** |
| 时长 | 3–8 h | **3 h** 起（工作 session） |

## 共用原则

- **主轨恒定**：钢琴 loop 整片不做段落切换、不做渐强渐弱 drama  
- **副轨不抢旋律**：划船为 **节奏纹理**，鸟鸣 **极 sparse**  
- **单一音效**：一轨一声源、一 Prompt 一动作  
- **反循环**：仅 L3/L4 鸟声 jitter；划船与湖面 loop **异长错相位**  
- **无歌词、无人声、无突然响度变化**  
- **流程**：钢琴源（MIDI/授权曲）→ RX / EQ → Reaper 叠环境 → 3 h 导出
