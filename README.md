# relaxASMR

自然之声 ASMR：**声音设计** + **画面设计** → Reaper 合成 **3 h / 8 h** 音视频。

---

## 模块

| 模块 | 说明 |
|------|------|
| [SoundDesign](./SoundDesign/README.md) | 五层声音 · 细雨 / 中雨 / 大雨 · 四场景 · 四时段 |
| [VisualDesign](./VisualDesign/README.md) | **文字**画面设计 · 全球森林 · 地区 × 季节 |
| [study_case.md](./study_case.md) | 参考案例 |

---

## 制作流程

```
选景（VisualDesign 地区 + 季节 + 时段）
  → 声音：H4e → RX → ElevenLabs → Reaper 音频
  → 画面：5s/10s loop 视频 → Reaper 视频轨 Loop
  → 渲染 3 h / 8 h ASMR 成片
```
