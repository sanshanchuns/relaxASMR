## 一、产品目标

从**一张参考截图**做出「同系列」雨 ASMR 视频：

| 要 | 不要 |
| --- | --- |
| 材质 / 色调 / 雨档氛围 / 写实自然 **像参考图** | 几乎同一构图、同一摆位的「静帧微动」 |
| 换景别或角度或主体占比（同系列异构） | 首尾帧同图锁死 |
| 前景主体上有可见雨击打与叶前雨丝 | 雨只画在主体后面 / 背景里 |

即梦「全能参考」：单图作题材锚点；**保留什么、调整什么必须写在 prompt（六槽原子）里**。

---

## 二、公式：保留 + 调整

```
保留（从图来） + 调整（文字主导） = 同系列异构视频
```

- **只写保留** → 模型贴原图  
- **只写调整** → 题材跑偏  
- **两边都写** → 满足「参考但不一模一样」

Jimeng 说的「改动作、加动态、换氛围、调运镜」全部属于 **调整**。

### 约束槽不够当「如何改」（2026-08-08 · Jimeng Agent 确认）

问：约束里只有「不复制参考图原有构图」「同系列异构」，镜头/主体没有写清改成什么景别/角度/占比时，Seedance 会怎样？

| | Jimeng 结论 |
| --- | --- |
| 仅负面约束 | 会在「不复制」前提下 **自我发挥**换构图（不是完全锁死不动），但结果 **随机、不可控** |
| 要稳定异构 | **必须**在镜头/主体等槽写 **正向调整**（景别、视角、主体占比等）；仅靠约束不够 |

因此：约束里的「勿复制 / 同系列异构」只作边界；**如何改**必须写在 camera（必）/ subject（可）的正向原子里。

**写法要求（给 Agent，禁止背例句）**：先看清参考图当前景别/视角/主体占比，再写一条与之**不同**的目标构图；维度从「景别、视角、主体占比、入画主体」里至少覆盖两项。规范里若出现示例句，**一律不得原样写入六槽**。

## 三、六槽怎么写

| 槽 | 保留（锚点） | 调整（必写差异） |
| --- | --- | --- |
| 主体 | 阔叶/水珠/细枝等题材 | 换哪簇叶入画、占比、略侧（据实图自拟，勿套话） |
| 动作 | — | **主调整槽**：前景雨丝、砸叶溅花、水珠被击落；**凡运动须周期往复** |
| 环境 | 林间/冷湿 | 远景层次、雾气密度（勿把光学虚化写成朦胧） |
| 镜头 | 浅景深可留 | **构图正向调整主槽**：据实图写目标景别/视角/占比；固定机位 |
| 风格 | 写实自然；叶色可嫩绿鲜亮但不艳阳高饱和 | 少改 |
| 约束 | 无人物；可写勿复制构图 | **不能替代**镜头如何改、**也不能**用「循环过渡自然」代替动作的周期往复 |

产品建议（可改）：`固定机位拍摄` · `写实自然风格` · `无人物`。六槽均可自由增删原子。

### 动作槽：周期往复才能 loop（硬要求）

成片要可无缝循环时，**运动必须写在 action 里，且是周期往复**（叶片小幅来回摆、雨丝持续下落节奏、水珠滚落再挂珠等）。  
**约束里写「循环过渡自然 / seamless loop」没用**——Seedance 不会因此把单向运动改成可 loop；必须改 action 措辞本身。

## 四、雨与景深（常漏）

1. 参考图**已有雨** → **根据参考图**判断雨档（小/中、大、暴雨），不以 GUI 雨型强制覆盖；无雨才用 GUI。  
2. **前景雨**：雨丝在最前清晰主体之前/之上穿过并击打；禁止雨只在叶后。  
3. **光学虚化**进镜头槽；**大气雾气/雨幕**进环境槽。

## 六、自检（草稿与审核共用）

- [ ] 是否同时有保留类原子与调整类原子  
- [ ] **镜头（或主体）是否有正向构图调整**（景别/视角/占比），而非只在约束写「勿复制」  
- [ ] 构图原子是否**针对本张参考图**自拟，而非规范套话/示例原文  
- [ ] action 是否含前景击打 / 叶前雨丝  
- [ ] action 里凡运动是否均为**周期往复**（非单向飘走/单次下落完结）  
- [ ] 是否误把「循环过渡自然」等写进约束却未改 action  
- [ ] 雨档是否与参考图一致（有雨时）  
- [ ] 虚化是否写在镜头而非「朦胧环境」糊弄
