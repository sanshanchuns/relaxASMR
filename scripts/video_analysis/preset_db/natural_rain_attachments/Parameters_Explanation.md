# Natural Rain VST 组合生成说明与参数详解

本目录下的 `natural_presets/` 文件夹包含了 **2160 个** 基于自然场景离散值数学排列组合生成的 `.rain` 配置文件。

## 一、数学排列组合构成 (共 2160 种)

生成的预设由 **三个环境层** 与 **九种 Rainfall 气候模板** 进行全排列组合而成。

计算公式：`20 (Distant) × 2 (Space) × 6 (Close) × 9 (气候模板) = 2160`

### 环境层 (Environment Layers)
- **Distant 层 (20种)**: 全部 20 种原生 Distant 层，例如 Airy Breeze, Broadband Shower 等，负责背景风声、远方气流和雨幕的深度。
- **Space 层 (2种纯自然)**: `05.Foliage Canopy (树冠)`, `06.Foliage Dense (茂密树林)`。排除了城市和建筑物。
- **Close 层 (6种纯自然)**: `04.Foliage Lush (茂密植被)`, `05.Foliage Yielding (稀疏植被)`, `09.Stone Echoing (石头/石墙)`, `11.Wood Roof (木屋顶)`, `14.Concrete (混凝土石板)`, `17.Water (水面)`。负责前景雨滴打在表面上的物理质感。

## 二、气候编号说明（直观雨量序）

原始 VST 导出按**生成顺序**编号 C1–C9，听感上并不单调递增。现统一按**直观雨量从小到大**重排：

| 新编号 | 旧编号 | 标签 | 听感 |
|--------|--------|------|------|
| C1 | C1 | 极轻细雨 近贴 | 最轻：稀疏滴落 |
| C2 | **C9** | 极轻密集 近贴 | 极轻但密湿，滴答成线 |
| C3 | C2 | 小阵雨 中距 | 小雨 |
| C4 | C3 | 中雨 均衡 | 标准中雨 |
| C5 | C4 | 中雨极湿 近贴 | 中雨 + 极湿近景 |
| C6 | C5 | 中雨极湿 远方 | 中雨 + 极湿远景 |
| C7 | C8 | 中雨密集 干燥 远方 | 中雨量、高密度、偏干 |
| C8 | C6 | 大雨 近贴 | 大雨近景 |
| C9 | C7 | 大雨 远方 | 暴雨远景 |

代码中的映射常量见 `scripts/config/common_constants.py`（`CLIMATE_LEGACY_TO_NEW`）。

## 三、Rainfall 气候模板参数详解

在提取了官方自然预设后，我们提纯了 `Intensity`, `Density`, `Wetness`, `Distance` 以及 `EQ (Mass/Strength/Presence)` 的离散分布值。我们将这些提取出的合法自然值捆绑成 9 种有物理现实意义的气候模板。

在插件底层中：
- `rfin`: **Intensity (强度)**，控制雨势大小，值越大高频打击感越强。
- `rfdn`: **Density (密度)**，控制雨滴的数量和密集度，值越大声音连贯感越强。
- `rffc`: **Wetness (湿度)**，决定水汽的浓厚感。
- `rfch`: **Distance (距离)**，`0.0` 为贴脸前景，`1.0` 为遥远的后景。
- `eq` 与 `bgeq`: 三个频段的 EQ（分别对应 Mass 低频厚度、Strength 中频力度、Presence 高频空气感）。

以下是 9 种气候模板（**新编号，按雨量从轻到重**）的参数取值与声学原理说明：

### 1. C1_极轻细雨_近贴 (Very Light Drip - Close)
*基于预设 19.极轻细雨 提取。旧编号 C1。*
- **rfin (0.0)**: 极轻，几乎没有猛烈敲击感。
- **rfdn (0.5)**: 稀疏的滴落。
- **rffc (0.5) / rfch (0.0)**: 较干，极度贴近听者耳朵。
- **EQ 特征**: 低频被削弱，极度强化高频 Presence (`eq3y=1.0`)。用于表现几滴雨水在耳边叶片上碎裂的声音。

### 2. C2_极轻密集_近贴 (Light Drip - Dense - Wet - Close)
*基于预设 07.滴水水洼 提取。旧编号 C9。*
- **rfin (0.0) / rfdn (1.0)**: 几乎没有击打强度，但是频率极高（滴答滴答连成线）。
- **rffc (0.82) / rfch (0.0)**: 极度湿润，距离极近。
- **EQ 特征**: 全频段平直（均在 0.5），只通过插件自身高密度的粒子合成器来生成大量的小水泡/泥泞音效。

### 3. C3_小阵雨_中距 (Light Shower - Mid)
*基于预设 11.秋日细雨 提取。旧编号 C2。*
- **rfin (0.25) / rfdn (0.55)**: 细雨连绵，雨量较小但密度适中。
- **rffc (0.65) / rfch (0.5)**: 环境开始变得湿润，听感退后到中距离。
- **EQ 特征**: 全频段平稳，没有过分突出某个频段。提供白噪音般的舒适感。

### 4. C4_中雨_均衡 (Medium Rain - Balanced)
*基于预设 15.森林叶雨 提取。旧编号 C3。*
- **rfin (0.5) / rfdn (0.55)**: 标准雨声，强度与密度处于绝对平衡点。
- **rffc (0.65) / rfch (0.5)**: 均衡的湿度与距离感。
- **EQ 特征**: 中低频 (Mass) 被稍微拉高，强化雨林中那种厚实的“沙沙”白噪音底噪。

### 5. C5_中雨极湿_近贴 (Medium Rain - Wet - Close)
*基于预设 10.林荫细雨 提取。旧编号 C4。*
- **rfin (0.5) / rfdn (0.55)**: 标准雨声。
- **rffc (0.82) / rfch (0.0)**: 极高的湿度 (`0.82`) 和极近的距离 (`0.0`)，产生明显的水泡音。
- **EQ 特征**: 远景高频 (`bgeq3x=1.0`) 被完全打开，用于模拟茂密树冠上方传来的白噪音，而前景雨水依然具有滴落的湿润感。

### 6. C6_中雨极湿_远方 (Medium Rain - Wet - Far)
*旧编号 C5。*
- **rfin (0.5) / rfdn (0.55)**: 标准雨声。
- **rffc (0.82) / rfch (1.0)**: 极高湿度，但听感被推到极远 (`1.0`)。
- **EQ 特征**: 由于是远距离，所有的高低频 EQ 全部回归 0.5 居中（空气吸收效应导致频段圆滑），声音被柔化成远方的背景嗡鸣。

### 7. C7_中雨密集_干燥_远方 (Medium Dense - Dry - Far)
*基于预设 24.湿地雨林 提取。旧编号 C8。*
- **rfin (0.5) / rfdn (1.0)**: 强度中等，但雨滴数量极多。
- **rffc (0.5) / rfch (1.0)**: 水汽感低（干），远距离。
- **EQ 特征**: 低频被削弱，这主要用于配合那些拥有强烈环境风声的 Distant 层，作为氛围点缀而不会抢走风声的厚度。

### 8. C8_大雨_近贴 (Heavy Shower - Dense - Close)
*基于预设 21.水面涟漪 提取。旧编号 C6。*
- **rfin (0.69) / rfdn (1.0)**: 强度较大，密度达到满载 (`1.0`)，模拟暴雨砸向表面的连贯声。
- **rffc (0.82) / rfch (0.0)**: 高湿润，极度近景。
- **EQ 特征**: 前景 EQ 中高频达到最大 (`eq2y=0.91`, `eq3y=1.0`)，旨在制造雨水砸在水面或树叶上产生的清脆破裂感（Splashing）。

### 9. C9_大雨_远方 (Heavy Shower - Dense - Far)
*基于预设 01.大树叶雨声 提取。旧编号 C7。*
- **rfin (0.69) / rfdn (1.0)**: 暴雨级别。
- **rffc (0.82) / rfch (1.0)**: 高湿润，远距离。
- **EQ 特征**: 背景 EQ 高频增益较大，旨在模拟远方传来的巨大雨帘声屏障（宽频白噪音）。

## 四、其他全局参数说明
所有这 2160 个配置共享以下相同的全局安全参数：
- **`glgn (Volume)` = 0.2**: 将输出音量设置在 20%，为了配合极端暴雨与混凝土等硬材质，强制留出巨大动态余量以绝对防止破音 (Clipping)。
- **`glon (Smart)` = 1.0**: 开启智能动态限制，确保不同强度的雨声在切换时音量不会出现灾难级的跳跃。
- **`gldr (Plugin On)` = 1.0**: 启用引擎。
- **`spbl (Space Blend)` = 0.5**: 空间层与远景层对半混合。
- **`sucd (Close Drops)` = 0.8**: 提供足够的前景雨滴击打粒子数。

### 四维速查

| 维度 | 模板中的体现 |
|------|-------------|
| 雨量级 | C1 极轻稀 → C2 极轻密 → C3 小 → C4–C6 中 → C7 中密 → C8/C9 大 |
| 密度 | 稀疏(0.5) vs 密集(1.0) |
| 湿度 | 干(0.5) vs 极湿(0.82) |
| 距离 | 近贴(0.0) vs 中距(0.5) vs 远方(1.0) |
| 音色/EQ | 各模板有不同 Mass/Presence 侧重 |
