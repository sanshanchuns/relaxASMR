# 混音打分规则 · 包裹感 / 安全感

> 把 [`design/rule.md`](../rule.md) 落成可执行的打分标准。  
> 自动脚本：`benchmark/score.py`（RS-PASS · mp4/wav **前 1800 秒**（不足则全长）· `benchmark/theory.md` §四）。

## 打分对象：成品 vs 轨道

| 维度 | 用什么打更准 | 原因 |
|------|--------------|------|
| 安全感（连续声床、尖峰、高频、密度） | **渲染成品 wav** | 听众听到的是混音叠加结果，单轨测不出遮蔽与总高频 |
| 包裹感的 立体声宽度 / 低频托底 / 混响尾 | **渲染成品 wav** | 混音后才成立，单轨不代表总和 |
| 包裹感的 距离层数 / 近中远比例 | **配方（轨道/asmr_config）** | 混音后无法拆回，配方里一目了然 |

**结论**：对 **成品 mp4/wav** 用 `benchmark/score.py` 做 RS-PASS 打分；混音结构（近中远层）仍建议对照配方人工检查。

## 一、包裹感 Immersion（满分 10）

| 子项 | 权重 | 0–1 评分标准 | 来源 |
|------|------|--------------|------|
| 层次完整度 | 2.5 | 近/中/远三区都有声 →1；缺一区 ≈0.67；只剩一区 ≈0.33 | 配方 |
| 近中远比例 | 2.5 | 越接近 40/40/20 越高；`1 − 0.5·Σ|实际−理想|` | 配方 |
| 立体声宽度 | 3.0 | `side/mid` 能量比：0(单声)→0，≥0.6→1；参考 L/R 相关越低越宽 | 成品 |
| 低频托底 | 2.0 | (sub_low+low_mid) 占比，峰值在 ~25%：`1 − |占比−25|/25` | 成品 |

距离层默认映射（配方人工对照，benchmark 脚本不读 asmr_config）：

| 层 | 距离区 |
|----|--------|
| 1_base 空气/底噪 | 远 0.6 / 中 0.4 |
| 2_rain 主雨 | 近 0.5 / 中 0.5 |
| 3_impact 击打 | 近 |
| 4_water 水面 | 中 |
| 5_env 环境 | 中 0.5 / 远 0.5 |
| 6_life 远生物 | 远 |
| 7_comfort 庇护 | 近 |

> 稀疏(scatter)层对「连续声场」贡献按 ×0.4 折算。

## 二、安全感 Safety（满分 10）

| 子项 | 权重 | 0–1 评分标准 | 来源 |
|------|------|--------------|------|
| 连续声床 | 3.0 | 窗 RMS 波动 std：≤2dB→1，≥8dB→0；有静音空隙按比例扣 | 成品 |
| 尖峰控制 | 2.5 | 突增(>6dB)事件：≤2/min→1，≥20/min→0；99.9分位 crest>14dB 再软扣 | 成品 |
| 高频克制 | 2.0 | 3–8kHz 能量占比：≤10%→1，≥35%→0（rule.md §五 最敏感带） | 成品 |
| 密度 70/20/10 | 1.5 | 稳/变/惊 占比对 0.7/0.2/0.1：`1 − 0.5·Σ|实际−理想|` | 成品 |
| 宏观起伏 macro_drift | （并入密度 25%） | `2_rain` 配 `vol_envelope` 且 depth 0.05–0.15 →1；有但过弱/过强 →0.5 | 配方 |
| 安全声源 | 1.0 | 白名单声源占比 −（雷/爆/乌鸦/车/人声等）占比 | 配方 |

安全声源白名单（rule.md §八 + §四 近处可控）：雨打树叶、湖水拍岸、木船、微风树叶、远处鸟鸣、壁炉、竹林风、溪流、伞/屋檐/帐篷庇护。  
扣分声源：雷、爆、乌鸦尖叫、警报、城市车流、人声、突兀钟声。

## 三、凭耳朵快速打分（无脚本时）

按每项「明显达标=1 / 部分=0.5 / 不达标=0」估分后乘权重相加：

1. **连续声床**：闭眼听 30s，雨/环境是否一直在、无断点、无忽大忽小。
2. **尖峰**：是否出现让你「注意一下」的突兀声（越少越好）。
3. **高频**：是否发尖、发刺、听久耳累（雨丝/鸟易超标）。
4. **密度**：大部分时间稳定，偶有变化与惊喜，而非每秒都在变。
5. **宏观起伏**：长时听是否仍像「同一条 loop」——主雨层应有 **极慢** 的一轮强弱（整片一个波峰/波谷即可）。
6. **距离层**：能否听出近(自己)、中(中景)、远(远处)至少三层。
7. **宽度**：是否「被包住」而非声音都从正前方一个点出来。
8. **低频**：是否有温暖托底，而非单薄飘。

## 五、theory.md RS-PASS benchmark（`benchmark/score.py`）

依据 **雨声舒缓安逸度评估标准 RS-PASS**（theory.md §四）与 **三色噪声分类**（§一），对渲染 **mp4/wav 前 1800s**（不足则全长）打分：

| 指标 | 权重 | 目标域 |
|------|------|--------|
| N_5 动态峰值响度 | 25% | 助眠 ≤3 Sone / 专注 ≤8 Sone |
| S_50 尖锐度 | 20% | ≤1.1 Acum（白噪类型容忍至 1.35） |
| R_5 粗糙度 | 15% | ≤0.08 Asper |
| IACC | 15% | ≤0.3（越低包裹感越强） |
| F_50 波动强度 | 10% | 0.05–0.15 Vacil |
| SI 光谱不规则度 | 10% | 中高水平 |
| T_max 纯音色调度 | 5% | ≤0.02 |

**色噪声类型**（`benchmark/noise_type.py`）：PSD 斜率分类 pink / white / brown，输出类型贴合度；综合分 = **85% RS-PASS + 15% 类型贴合**。省略 `--mode` 时按主类型自动选 sleep（粉/棕）或 focus（白）。

**Reaper 修改建议**（`--rpp` 或从媒体路径自动推断）：读取轨道 vol/FX 与 `asmr_config.lua`，对照 theory §五 前景 60% / 中景 30% / 背景 10%，输出 ReaEQ、素材替换、层能量等建议（`benchmark/recommendations.py`）。

```bash
python3 benchmark/score.py path/to/render.mp4
python3 benchmark/score.py path/to/mix.wav --mode focus --json --duration 1800
python3 benchmark/score.py path/to/render.mp4 --rpp Reaper/Projects/Rain/subprojects/MVI_6918/MVI_6918.rpp
```

等级：≥90 极品 · 75–89 优秀 · 60–74 普通 · <60 劣质。实现见 `benchmark/rs_pass.py`（代理量，非实验室级）。
