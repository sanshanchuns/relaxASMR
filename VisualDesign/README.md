## 制作流程

```
文字选景（地区 + 季节 + 时段）
  → 生成 / 实拍 5s 或 10s 无缝 loop
  → Reaper：视频轨 Loop + SoundDesign 音频
  → 渲染 3 h / 8 h
```

---

## 与 SoundDesign 对齐

| 画面维度 | 声音维度 |
|----------|----------|
| 地区 · 生物群系 | Prompt 中的树种 / 地理词 |
| 季节 | 叶量、色彩、地面状态（湿叶 / 裸枝 / 常绿） |
| 时段（夜/黎明/黄昏/白天） | [四时段矩阵](../SoundDesign/README.md) |

默认声音参考：[medium_rain/night/forest](../SoundDesign/medium_rain/night/forest.md)（温带 · 夜 · 中雨 · 树下坐听雨）。

**默认画面 Prompt**：欧洲 · 45–55°N · **秋 · night** → [prompts/europe.md](./forest/prompts/europe.md) 温带落叶阔叶林表格。
