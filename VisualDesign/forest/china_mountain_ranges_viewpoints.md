# 中国森林 ASMR · 机位主表

**一行 = 一个可选机位**。按 **生物群系 → 省 → 景区** 排序。

1. 在总表中选一行（建议 **★** 首选机位）

2. 复制 **Prompt 模板**，改 `{雨势}` `{时段}`

3. 画面词对照 [biomes_rain_scenes.md](./biomes_rain_scenes.md) 同生物群系 × 雨势 × 时段

4. 音频对标 [SoundDesign](../../SoundDesign/README.md)


省区生物群系分布 → [china_biomes_sites.md](./china_biomes_sites.md)

## 列说明

| 列 | 用途 |
|----|------|
| ID | 编号，便于引用 |
| 生物群系 | 决定色调；1 雨林 → 6 泰加 |
| 山脉 | 地理分组 |
| 省 · 市 | 行政标签（如 **重庆 · 武隆**；搜「武隆」请搜本列或景区列） |
| 景区 | 公园 / 子景区（武隆系写作 **武隆·天生三桥** 等） |
| 机位 | 具体观景点；**★** = 首选全景机位 |
| 镜头 | **俯瞰** = 默认视频；**谷底框景** = 武隆天福官驿类 |
| 框景主体 | 画面远景中心 |
| Prompt 模板 | 可直接用于出图 / 视频 |

固定镜头 · 禁 pan/zoom → [rule.md](../rule.md)
