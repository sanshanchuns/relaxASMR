# 森林 · 画面设计说明

主场景为 **森林**。本文档体系按 **地区 × 季节** 描述画面，供选景、写视频 Prompt、与 SoundDesign 对齐。

---

## 季节体系（两类）

| 气候区 | 季节划分 | 适用地区 |
|--------|----------|----------|
| **温带 / 寒带** | 春 · 夏 · 秋 · 冬（四季） | 欧洲、北美、东亚、新西兰南部、智利南部 |
| **热带 / 部分亚热带** | **湿季 · 干季**（或雨季 · 非雨季） | 亚马逊、刚果、东南亚、印度季风区 |

热带低纬全年高温，**没有「冬季落叶」**；季节感来自 **降水多寡** 与 **云量**，而非气温周期。文档中热带地区用 **湿季 / 干季**；温带用 **春夏秋冬**。

---
