# 森林生物群系 · 雨景画面描述

按 **纬度 · 温度 · 降水** 划分的六类森林，分别给出 **小雨 / 中雨 / 大雨** × **黎明 / 白天 / 黄昏 / 夜晚** 的固定机位画面描述，供选景、写视频 Prompt、与 [SoundDesign](../../SoundDesign/README.md) 对齐。

**机位约定**（与 [rule.md](../rule.md) 一致）：固定镜头 · 5 s / 10 s 无缝 loop · 微动仅限雨丝、叶尖、雾缕。**中国选景优先高处俯瞰**，见 [机位主表](./china_mountain_ranges_viewpoints.md)。

**SoundDesign 对应**：小雨 → `drizzle/` · 中雨 → `medium_rain/` · 大雨 → `heavy_rain/` · 时段 → `dawn/` `day/` `dusk/` `night/`。

## 1. 热带雨林

**生态**：赤道附近，年均温 25–28°C，年降水 >2000 mm，几乎无干季。多层冠（ emergent / 主冠 / 林下），板根、气生植物、巨型蕨类，物种极度丰富。

### 小雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | 天幕自墨绿渐为灰青，超高 emergent 树梢勾出剪影；极细雨丝几乎悬浮，叶面挂满水珠，每片阔叶边缘串成透明珠链。林下幽暗，蕨类叶尖微颤，薄雾贴地缓移，偶见彩色羽冠鸟栖于高枝不动。整体低饱和、偏冷绿，仅东天一线浅灰亮。 |
| **白天** | 林冠密闭，天光被筛成无数柔白斑，落在多层阔叶上成碎钻感；小雨如雾，垂直感弱，更像空中悬浮的细沫。板根处苔厚色深，藤本垂落偶尔滴一颗水。色彩饱和中高：深绿冠、黄绿嫩叶、暗褐树干，无直射阳光。 |
| **黄昏** | 高冠层仍绿，但林内迅速沉为蓝绿；雨丝在暗背景里显银灰细线。远处主冠轮廓模糊，近处大叶反光减弱，仅留湿润高光。虫鸣位（画面外暗示）与雨丝同步，地面落叶层几乎不可见，全被阴影吞没。 |
| **夜晚** | 近乎全黑，仅冠层缝间漏下极弱天光，雨丝在暗处偶闪；阔叶湿面偶映一点冷白。固定机位看中层树干与垂藤，背景是深不可测的墨绿。无月光假设，适合 ASMR 纯雨夜。 |

### 中雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | 雨幕加厚，主冠层成连续灰绿拱顶；雨线斜密，打在阔叶上溅起细雾。东天灰白，林缘 emergent 树被勾亮。板根沟有浅流，落叶层泛深褐反光，蕨类被雨压弯后缓慢回弹——loop 微动点。 |
| **白天** | 中雨在多层冠上叠出白噪般的雨雾，天光漫射成均匀灰绿；偶尔一股风让高层叶浪传递，雨势视觉略增。近景一根覆满地衣的树干，中景板根与气生根，远景冠层融为一片雨云色。色彩：湿绿 + 灰白雨幕。 |
| **黄昏** | 雨未减，色温转冷；林内像浸在蓝绿玻璃里，雨线更亮、背景更暗。高枝仍有最后一点天光，林下已黑，仅近叶湿面反光。适合「雨林傍晚暴雨不止」的沉浸感。 |
| **夜晚** | 中雨在暗冠上敲出密织纹理，近叶被雨打颤，远处为纯黑 + 雨丝灰线。无雷。固定机位略仰 15°，见冠层底面与雨线交织。 |

### 大雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | 雨帘如幕，能见度降至数十米；巨冠在灰白天光下呈深绿块面，雨成束落下。板根间急流初现，落叶被冲贴地。整个画面高对比：亮雨帘 / 暗林体，偶有断枝坠叶穿过雨幕——单次 loop 内一次即可。 |
| **白天** | 大雨在 emergent 层打成水烟，主冠似沸腾；天光被雨幕完全打散成白灰。近景阔叶被雨流覆盖成连续水膜，色偏银绿。极少可见蓝天，整体像绿色隧道尽头的瀑布感。 |
| **黄昏** | 暴雨中黄昏几乎无暖色，仅天顶略浅灰；林体沉入深青黑，雨束在侧向余光里发亮。地面薄流横过画面下角，落叶层翻起暗色水花。 |
| **夜晚** | 大雨夜：全黑背景中雨丝成密灰白斜线，近树干被雨雾包裹。冠层不可辨，仅雨声与视觉白噪。固定机位，禁闪电。 |

## 2. 热带季雨林

**生态**：热带季风区（如西双版纳、印度半岛、东南亚北部），年降水 1000–2000 mm，**旱季 3–5 个月**。旱季部分乔木落叶，湿季冠层闭合如雨林；林下有竹、棕榈、季相明显。

### 小雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | 湿季：近似雨林但林隙略多，东天灰粉，细雨洒在半常绿冠上，旱季落叶树若仍秃枝则见细雨挂枝。干季末小雨：灰黄地面，稀疏冠层，雨丝清晰落地扬尘微雾。默认按 **湿季** 描述——多层绿，偶见裸枝区。 |
| **白天** | 湿季小雨，天光青白，阔叶与棕榈混生，叶面亮泽；竹丛叶尖垂珠串落。林缘可见季雨林特有的「绿—褐」斑块（落叶树 vs 常绿树）。雨细，地面红壤或腐殖土略暗。 |
| **黄昏** | 雨丝 + 略开的林窗，西天浅橙被雨幕柔化；常绿树仍深绿，落叶区呈灰褐枝网。虫鸣盛（画面外），近景一丛竹或棕榈，背景冠层渐黑。 |
| **夜晚** | 湿季夜雨：暗绿冠、细雨丝、近处竹干反光。干季则冠层稀疏，更多天光漏下，星点状——本条目默认 **湿季夜**。 |

### 中雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | 中雨打在混合冠层上，常绿树区密、落叶区疏，雨线疏密不均。东天灰亮，近景季相明显的阔叶（部分黄绿新叶）被雨洗亮。地面小径有浅洼反光。 |
| **白天** | 典型季风湿季午后感：中雨、云低、冠层绿浓，棕榈或 bamboo 在中景摇曳。雨幕灰白，林内亮度均匀，红壤路面积水映天。 |
| **黄昏** | 中雨延续，色温转冷；西向林隙若有将尽天光，呈灰橙条。落叶树区枝影加重，常绿树区仍绒绿。适合「季风林傍晚雨不停」。 |
| **夜晚** | 中雨夜，冠层黑绿，雨线密；近景阔叶或竹，中景见湿季才有的 dense understory 轮廓。 |

### 大雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | 湿季暴雨：雨帘封林，混合冠层成一片晃动的深绿；落叶区雨水穿枝而过成白线。地面径流在红壤上划深色痕，偶见棕榈大叶被雨压垂。 |
| **白天** | 大雨中能见度低，季风云压顶，整个画面灰绿； bamboo 或大型蕨在前景剧烈颤。常绿树区如瀑布，落叶区雨线更直。 |
| **黄昏** | 暴雨 + 黄昏 = 冷灰主导，极少暖色；林缘若有远山，完全消失在雨幕里。近景水流过根际，落叶被冲聚于画面一角。 |
| **夜晚** | 夜暴雨，黑中雨丝成幕；季雨林特有的「疏密冠层」在暗处难辨，仅前景植物被雨雾打亮。 |

## 3. 亚热带常绿阔叶林

**生态**：亚热带季风（中国华南、日本南部、美国东南部部分），冬暖夏热，年降水 1000–1500 mm，**终年常绿**，叶片革质、有光泽；常见樟、栲、青冈、月桂类。

### 小雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | 东天鱼肚白，细雨如纱；常绿阔叶在灰青天光下仍保深绿，叶面蜡光映白。林缘略薄，见远岚；近景枝杈层叠，每片叶缘挂珠。地面 moss 与落叶混层，色偏褐绿。典型 **梅雨前奏** 气质。 |
| **白天** | 阴天小雨，天光均匀灰白，无硬影；冠层圆整如绒球，阔叶反光成点点亮斑。中景石或旧木阶若有，表面水膜；色彩：青绿 + 灰天，饱和度中。 |
| **黄昏** | 细雨 + 暮光，整体转青灰；叶面高光由白转银，西天若有窄缝光，呈冷灰紫。林内快速变暗，近叶仍可见湿润纹理。 |
| **夜晚** | 夜雨细，冠层黑绿块面，雨丝在暗处细闪；近阔叶偶映微光。适合江南 / 日本南部 **梅夜** 意象，无月。 |

### 中雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | 中雨敲阔叶，声密视觉亦密；东天灰亮，冠层底面见雨雾。近景革质叶被雨洗成深绿，枝略下垂。地面小水洼，映灰天一条。 |
| **白天** | 标准亚热带雨中昼：云低、光散、雨线斜，整林青灰绿。冠层闭合，林隙少；若有石灯笼 / 苔石仅作文化暗示，不必出现。画面焦点在叶层与雨幕交界。 |
| **黄昏** | 中雨黄昏，色温冷；阔叶轮廓仍清，背景冠层融为深青。雨线比白天更亮、对比更高。地面流痕略明。 |
| **夜晚** | 中雨夜，固定机位平视冠层下缘；雨丝灰白，叶黑，偶见湿枝反光。与 SoundDesign 默认温带夜雨不同——**更绿、更密、更少裸枝**。 |

### 大雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | 暴雨洗林，阔叶翻飞露银灰背面；东天白灰，雨幕如墙。近枝被雨压弯回弹——loop 微动。地面径流，落叶贴地。 |
| **白天** | 大雨天光仍亮但完全漫射；整个画面雨雾白 + 深绿冠。革质叶上水流成线，枝杈间见瀑布式落水。能见度中低。 |
| **黄昏** | 暴雨傍晚，无暖 sunset，仅天顶略浅；林体冷青黑，雨束侧向可见。适合「台风雨 / 梅暴雨」视觉。 |
| **夜晚** | 夜暴雨，雨丝密幕，近叶在雨雾中偶亮；冠层与夜融为一片。禁雷。 |

## 4. 亚热带常绿硬叶林

**生态**：地中海气候（伊比利亚、意大利、希腊、加州 chaparral 边缘、澳大利亚西南），**夏热干、冬温湿**。硬叶、小叶、蜡质（马鞭草、橡、橄榄类），灌木层明显，林相偏矮、耐旱。

### 小雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | **冬季湿季** 默认：细雨落在硬叶上，叶缘厚、反光如蜡；东天灰粉，林相偏矮，冠层不连续，见更多天。橄榄色 / 灰绿主调，干土味视觉暗示——土褐露于灌木间。 |
| **白天** | 冬雨 daytime：云厚、光柔，硬叶丛成灰绿团块；细雨垂直，地面砾石与枯草沾湿变深。夏雨季极少，若用则雨细但土仍黄、叶略卷——本表以 **冬季雨** 为主。 |
| **黄昏** | 冬雨黄昏：罕见暖色，西天灰橙条被雨柔化；硬叶边缘仍亮，灌丛沉为暗绿块。石质地面若有，映冷天光。 |
| **夜晚** | 冬夜小雨，矮冠、星隙多；雨丝在暗空可见，灌木轮廓如剪影。整体偏 **低饱和、灰绿、开阔**，非密闭高冠。 |

### 中雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | 中雨打在硬叶上，声脆视觉亦「硬」——叶少大、雨点跳溅明显。东天灰白，灌层与散生乔木交错，林窗多于雨林。土路积水浅。 |
| **白天** | 地中海冬雨中昼：天灰、雨密、植被灰绿；可见典型 sclerophyll 叶形（小、厚、边微卷）。远景若有缓坡，雨幕均匀。 |
| **黄昏** | 中雨 + 暮，色冷；硬叶团块变深，天空灰紫。地面枯枝与湿土对比加强。 |
| **夜晚** | 中雨夜，灌木层为主角，乔木稀疏；雨线清晰，背景暗蓝灰。与温带阔叶林比 **更疏、更矮、更蜡质**。 |

### 大雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | 冬暴雨：雨帘、矮林、土石坡径流；硬叶被雨流覆盖。东天白灰，对比强。偶见断枯枝——loop 一次即可。 |
| **白天** | 大雨中 visibility 降，灌丛成湿暗团，散生橡类在雨雾中如剪影。整体 **黄褐土 + 灰绿叶 + 白雨**，地中海冬季风暴感。 |
| **黄昏** | 暴雨黄昏，天暗雨亮；西向无典型 sunset，仅雨幕灰白。径流横穿画面下缘。 |
| **夜晚** | 夜暴雨，矮林灌丛在雨雾中边界模糊；雨丝密，星月不可见。 |

## 5. 温带落叶阔叶林

**生态**：温带季风或海洋性气候（中欧、中国东北/华北山地、阿巴拉契亚），四季分明。**秋落春芽**，优势种枫、橡、桦、山毛榉；林下有丰富落叶层。

> 雨景随 **叶态季相** 略异：默认 **夏绿 / 秋黄 / 冬裸** 三态中，**夏—秋** 为最常见 ASMR 设定；冬雨强调裸枝，春雨强调嫩绿。

### 小雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | 细雨挂枝——**有叶季**：枫橡叶尖垂珠，东天灰蓝，林冠绒绿带黄（早秋）。**裸枝季**：雨丝挂 bare branches，天青灰，地面积雪或褐叶。默认 **秋末**：黄绿混冠 + 细雨 + 冷灰黎明。 |
| **白天** | 小雨昼：云厚天白，叶幕筛光成软斑（有叶）；或裸枝季见完整枝网与灰天。近景落叶层湿暗，桦皮白干若入画作亮点。色：黄绿 / 褐 / 灰。 |
| **黄昏** | 细雨暮：有叶季西天窄缝冷橙，湿叶反光；裸枝季枝影如墨画。地面落叶被雨贴实，反光弱。 |
| **夜晚** | 夜雨细，冠层黑，偶有湿枝映微光；**树下听雨** 经典场景——粗干占画面一侧，背景枝网 + 雨丝。与项目默认 SoundDesign 场景最接近。 |

### 中雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | 中雨敲叶或敲枝；东天灰亮，秋林黄绿，雨线斜。近干苔痕、远冠模糊。地面小洼，落叶漂于水面。 |
| **白天** | 温带典型 **阴雨中昼**：均匀灰天、中雨、阔叶林冠如深绿 / 黄褐云盖（季相而定）。固定机位略仰，见冠层底与雨幕交界。 |
| **黄昏** | 中雨黄昏，冷色；湿叶或湿枝对比度升。林内暗，林缘天光略亮——适合 8 h 夜前过渡（若接 night 则偏 dusk）。 |
| **夜晚** | 中雨夜，项目主场景：树下、暗林、雨线密、近枝湿亮。可含撑伞听点暗示（伞沿不入画或仅边缘）。 |

### 大雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | 暴雨秋林：雨帘、黄叶被打颤、枝弯；东天白灰。地面径流冲落叶，汇于画面下角。 |
| **白天** | 大雨昼仍偏亮：雨幕白、冠层深，叶或枝承雨成瀑布点。能见度中，远景融于雨雾。 |
| **黄昏** | 暴雨 + 暮，无暖色 sunset；雨亮林暗，枝网如铁线。 |
| **夜晚** | 夜暴雨，黑 + 密雨丝；近树干水痕，远冠不可辨。禁雷（与 SoundDesign night forest 一致）。 |

## 6. 亚寒带针叶林（泰加林）

**生态**：北半球高纬（西伯利亚、加拿大、北欧、阿拉斯加），冬季长、夏季短，年降水 300–600 mm 以雪为主，**夏季亦有多雨期**。优势种 spruce、fir、pine、larch（落叶松）；林相疏密相间，地衣、苔藓、矮灌木。

### 小雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | 夏/初秋雨细：针叶梢挂珠，东天灰紫，树干直、间距大，见隙天。色偏 **冷蓝绿 + 灰**，地衣灰绿贴干。冬则雨雪或冻雨——本表默认 **无积雪的夏秋小雨**。 |
| **白天** | 小雨昼：云低灰白，针叶层如暗绿波浪，雨细几乎垂直；桦类若混交则白干点景。地面 moss 饱和变深，倒木覆苔。 |
| **黄昏** | 细雨暮，泰加快速变暗；针叶剪影 against 灰紫天，雨丝渐亮。远景树干重复韵律，透视感强。 |
| **夜晚** | 夜雨细，针叶黑簇、雨丝灰；夏季短夜仍全黑。固定机位看 mid-trunk，背景疏冠。 |

### 中雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | 中雨敲针叶，声密如沙；东天灰亮，近景松枝微颤，树脂干白痕若可见。地面浅流过 moss，色冷。 |
| **白天** | 泰加雨中昼：天灰、雨密、针叶深绿偏青；林相 **疏朗**，可见 depth。与中纬阔叶林比 **更直、更疏、更冷**。 |
| **黄昏** | 中雨黄昏，冷青黑；针叶层仍辨，天顶灰条。地面湿 moss 反光弱。 |
| **夜晚** | 中雨夜，黑中见雨线划过直干；近枝湿暗。适合 boreal night drizzle / medium rain 对齐。 |

### 大雨

| 时段 | 画面描述 |
|------|----------|
| **黎明** | 泰加暴雨：雨帘、针枝低垂、白干暗叶；东天白灰。倒木与径流，泥炭色地面。 |
| **白天** | 大雨昼，能见度降；针叶如绿色墙在雨雾中后退。整体 **青灰 + 白雨**，少暖色。 |
| **黄昏** | 暴雨暮，迅速入夜感；雨亮、林黑、干直。 |
| **夜晚** | 夜暴雨，雨幕占画面大部，直干局部被雨雾打亮；背景纯黑。全球面积最大森林带的 **冷、疏、长干** 语义。 |

## 使用说明

1. **选定生物群系** → 对应 SoundDesign 雨势与时段文档（如 [medium_rain/night/forest](../../SoundDesign/medium_rain/night/forest.md)）。
2. **季相微调**：温带落叶林、热带季雨林需注明湿季/干季或有无叶，上表已标注默认假设。
3. **写视频 Prompt**：从表中提取 **光线 + 冠层 + 雨态 + 主色** 四句，后缀加 `fixed camera, seamless loop, no zoom`（见 [prompts/README.md](./prompts/README.md) 若存在）。
4. **默认 ASMR 场景**：温带落叶阔叶林 · 中雨 · 夜 · 树下 — 与本项目 SoundDesign 主工程一致；画面可换生物群系但需同步调整 SoundDesign 层（如雨林增加 distant canopy drip，泰加减少蛙鸣等）。
5. **中国取景**：省区与景区清单见 [china_biomes_sites.md](./china_biomes_sites.md)；**经典机位按山脉**见 [china_mountain_ranges_viewpoints.md](./china_mountain_ranges_viewpoints.md)。
