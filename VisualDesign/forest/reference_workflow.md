# 机位创作流程 · 攻略实景 → 天气 / 时段变体

每个机位 **先锚定真实构图**，再在同一机位上扩展 **天气 × 时段** 变体，供 ASMR 视频 loop 与 SoundDesign 对齐。

## 1. 参考图来源（按优先级）

| 来源 | 用途 | 检索技巧 |
|------|------|----------|
| **携程** 景点相册 / 游记 | 官方机位、季节覆盖全 | 景点页 → 相册 → 按「最新/最热」 |
| **小红书** | 网红机位、构图角度、滤镜真实感 | `{景区} {机位} 实拍` / `{景区} 机位攻略` |
| **马蜂窝 / 穷游** | 长线攻略、步行路线与机位顺序 | 游记正文 + 图片 EXIF 方向 |
| **景区官网 / 微信公号** | 权威命名、禁飞/禁拍区 | 武隆喀斯特、黄山等官方号 |
| **维基 / 世界遗产** | 地理结构、正式景名 | 南方喀斯特、中国丹霞组分 |

> 用户口语「猫头鹰」若指某攻略 App，流程相同：**先找 3–5 张同一机位实景**，确认机位方向一致后再创作。

**禁止**：无参考凭空生成地标；参考图之间机位方向不一致时混用。

### 出图前检查（必做，缺一不可）

- [ ] 已在 **携程** 景点相册 / Moments 找到 ≥1 张同机位实景
- [ ] 已在 **小红书** 或 **马蜂窝** 交叉确认构图方向一致
- [ ] 参考图已保存至 `assets/refs/CN-{id}_*.jpg/png`
- [ ] 已填写 `assets/refs/CN-{id}_*_anchor.md` 锚点表
- [ ] **以上完成后** 才允许调用出图

> 若无法下载参考图（站点防盗链），请 **手动保存** 攻略截图至 `refs/`，或粘贴参考图后再出图。

## 2. 单机场位工作流

```
① 主表选 ID
    ↓
② 携程 / 小红书搜实景（≥3 张，同机位同方向）
    ↓
③ 保存参考 → assets/refs/{id}_{机位}_ref.jpg
    ↓
④ 填写「机位锚点表」（见 §4）
    ↓
⑤ 按变体矩阵出图 → assets/{id}_{weather}_{time}.png
    ↓
⑥ Prompt 归档 + 与 SoundDesign 路径对齐
```

## 2.1 ASMR 封面 / 缩略图光色（与视频 loop 区分）

**问题**：按「雨西湖 / 梅雨」直译容易出 **阴灰、低饱和、大面积灰天**，适合水墨意境，**不适合 YouTube 封面**。

**封面参考** → `assets/refs/asmr_cover_bright_rain_style_ref.png`（亮、前景绿叶、远景主体、雨但不清郁）

| 维度 | ❌ 避免（阴郁版） | ✅ ASMR 封面 |
|------|-------------------|--------------|
| 天空 | 大片深灰、乌云压顶 | **亮阴天 / 柔白漫射**，灰区 ≤ 画面上 1/3 |
| 前景 | 无框景、直接远景 | **湿绿叶/竹梢/树枝** 框景，饱和绿 |
| 远景 | 与前景同灰 | **真实地标清晰可辨**（雷峰塔、瀑布、湖心岛…） |
| 雨 | 雨幕盖满画面 | 雨丝可见，但 **整体照度偏高**、「清新雨」非「暴雨压抑」 |
| 情绪 | 水墨、愁绪 | 治愈、通透、想点进去听 |

**创作公式**（真实景点 + 封面光色）：

```
构图/地标 ← 携程·小红书实景 ref（不变）
光色/层次 ← ASMR 亮雨封面 ref（可变：仅光色与前景框景）
```

**封面三层构图（ASMR 封面 · 浅景深）**：

| 层 | 对焦 | 内容 | 要点 |
|----|------|------|------|
| **近景** | **实焦 ★** | 亚热带常绿阔叶 **特写**（樟/青冈类） | 叶脉、叶面、**水珠**；占画面 **~60–70%** |
| **中景** | 虚化 | 林冠 / 坡树 | 柔焦绿块，承接近景 |
| **远景** | 虚化但**可辨认** | **西湖湖景** | 苏堤、湖心岛、**雷峰塔**轮廓、城廓天际 —— 逻辑上必糊，但观众应能认出「这是西湖」 |

| **雨（近景）** | **实焦 ★** | **雨丝 / 雨滴特写** | 斜向雨线 **铺满画面**、空中悬滴、叶面水珠；ASMR 封面核心层 |
| **雨（中景）** | 过渡 | 较细雨丝 | 随景深渐弱 |
| **雨（远景）** | 无 | — | 虚化区 **不加雨**，避免糊上加糊 |

> 雨只出现在 **对焦平面附近**；西湖 bokeh 保持干净色块 + 地标轮廓。

### 2.2 雨怎么画才不像「玻璃」？

**v9 问题**：整屏 **等距、等粗、半透明斜线** → 像 **窗玻璃上的雨痕** 或 PS 蒙版，不像真实摄影。

摄影里雨可见，靠的是 **光学 + 层次**，不是一层透明线：

| 手段 | 原理 | 封面用法 |
|------|------|----------|
| **逆光 / 侧逆光** | 雨滴是透明体，**背对光源**才发亮（[Photography Icon](https://photographyicon.com/how-to-photograph-rain/)） | 亮灰天在背景，雨丝在叶前被勾亮 |
| **快门分层** | 1/500+ **圆点**；1/60–1/125 **短斜线**；1/15 **雨帘**（[Camera Settings](https://camerasettings.com/guides/cheat-sheets/rain/)） | 近景：**圆滴 + 短 streak 混用**，不要全长线条 |
| **景深分层** | 只有 **某一距离平面** 上的雨清晰（[Nick Dale](https://www.nickdalephotography.com/blog/how-to-photograph-in-the-rain)） | 近景叶实焦；**叶前 10–30 cm** 有雨点；再远无雨 |
| **暗背景托亮** | 雨比背景亮才显形 | 虚化西湖略偏 **蓝灰深一度**，雨丝/水珠更亮 |
| **叶面交互** | 真雨先打在物体上 | **水珠停叶上** > 空中雨线；叶尖下垂滴、叶面溅微白 |

**❌ 避免（玻璃感）**

- 整幅均匀半透明斜线网格  
- 雨线穿过虚化背景（bokeh 区应无雨）  
- 雨与叶 **同一焦点平面** 却一条线盖住叶面  
- 过高对比「白色塑料条」

**✅ 近景雨三层（推荐 Prompt 结构）**

```
近景雨 A：叶面水珠（实焦，v5 已有）
近景雨 B：叶前浅景深 — 少量 **圆点 + 短 streak**（1/100s 感），密度中等，非满屏
中景雨：可选 2–3 条较长 streak，已略虚
远景：无空中雨，仅湖面 bokeh
```

**中大雨 · 下落感（v11 方向）**

| 雨势 | 快门感 | 画面 |
|------|--------|------|
| 小雨 | 1/500 | 圆点 + 叶面水珠为主 |
| **中雨** | **1/60–1/125** | **斜向短—中 streak**，有运动模糊，密度中等 |
| **大雨** | **1/30–1/60** | streak 更长更密，局部雨帘，仍 **非满屏等距玻璃线** |

近景区：streak + 叶面水珠 **叠加**；远景 bokeh：**无空中雨**。

## 3. 变体矩阵（每个 ★ 机位至少做）

### 天气（与 SoundDesign 对齐）

| 天气 | SoundDesign | 画面要点 |
|------|-------------|----------|
| 晴 | （可选 `day/` 无雨版） | 直射/侧光、饱和绿、可见远景 |
| 小雨 | `drizzle/` | 细雨丝、叶面挂珠、天光仍亮 |
| 中雨 | `medium_rain/` | **默认 ASMR**；雨幕、灰天、谷雾 |
| 大雨 | `heavy_rain/` | 雨帘、低能见度、高对比 |

### 时段（与 SoundDesign 四时段对齐）

| 时段 | SoundDesign | 画面要点 |
|------|-------------|----------|
| 黎明 | `dawn/` | 东天灰亮、冷色、薄雾 |
| 白天 | `day/` | 均匀漫射或侧光 |
| 黄昏 | `dusk/` | 暖侧光、剪影加重 |
| 夜晚 | `night/` | 低照度、冷蓝；武隆驿站可点灯笼 |

**命名**：`{id}_{机位slug}_{weather}_{time}.png`  
例：`CN-194a_tianfuguan_rim_medium_rain_day.png`

**最小集（★ 机位）**：`medium_rain × day` + `medium_rain × dawn` + `drizzle × day`  
**扩展集**：+ 晴 day + 黄昏 + 夜

## 4. 机位锚点表（模板）

每个 ★ 机位在 `assets/refs/` 旁维护一条锚点记录（可写在主表备注或单独 `refs/{id}.md`）：

| 字段 | 说明 |
|------|------|
| ID | 主表编号 |
| 机位正式名 | 与景区指示牌一致 |
| **相机位置** | 在哪条栈道/台/峰 |
| **朝向** | 俯瞰谁、框景谁 |
| **参考图** | `refs/` 文件名 + 来源链接 |
| **地标不变量** | 出变体时不得改：建筑轮廓、桥拱、山体结构 |
| **可变项** | 仅改：天光、雨、雾、叶湿反光 |

## 5. 武隆 · 为何搜「武隆」全是天福官驿？

| 原因 | 说明 |
|------|------|
| **官方海报机位** | 天龙桥 rim **俯瞰** 谷底天福官驿 — 武隆 / 天生三桥 / 南方喀斯特 宣传图几乎都用此角度 |
| **影视锚定** | 《满城尽带黄金甲》唯一外景；游客复刻同一构图 |
| **动线必经** | 天生三桥环线必经驿站，栈道固定机位，易拍、易传播 |
| **SEO 聚合** | 小红书 / 携程「武隆」标签下，此图点赞最高 → 算法反复推荐 |
| **与「谷底仰拍」不同** | 攻略里的「天福官驿」= **桥上往下看**；不是谷底往上看桥拱 |

武隆 **不止** 这一机位，主表另有：

| ID | 景区 | 机位 | 与「海报图」关系 |
|----|------|------|------------------|
| **CN-194a** | 武隆·天生三桥 | **天龙桥 rim · 俯瞰天福官驿** | = 你搜到的经典图 ★ |
| CN-194b | 武隆·天生三桥 | 天福官驿 · 谷底仰观桥拱 | 不同方向，影视 Low angle |
| CN-193 | 武隆·天生三桥 | 天坑口 | 顶缘看三桥两坑 |
| CN-190 | 武隆·仙女山 | 大草原 | 高山草甸，完全不同景型 |
| CN-209 | 武隆·龙水峡地缝 | 一线天 | 地缝，非天坑 |
