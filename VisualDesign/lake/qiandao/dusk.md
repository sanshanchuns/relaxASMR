# 千岛湖 · 黄昏 · 视觉规格

**机位** CN-118 中心湖区 · **近水面平视远眺群山** · **时段** 黄昏 · **用途** 湖景 loop / YouTube 封面 / 静心工作 BGM 配套画面

---

## 画面描述（Prompt 基准）

固定低机位贴近平静湖面：前景为碧玉色水面与细微波纹、天光倒影；中景开阔水道；远景 **层叠群山与森林岛丘** 在暮色中呈青蓝剪影，西向山脊染 **暖金—琥珀** 余晖。相机高度近水面（非航拍俯瞰），地平线偏低，天空占上 1/3。无雨、无雷、无大船；微动仅 **水面细波**（5–10 s loop）。

---

## 光色（ASMR 封面友好）

| 维度 | 要求 |
|------|------|
| 天空 | 上 1/3 渐变：西暖东冷，**避免** 整屏深灰 |
| 湖水 | 主色 **碧玉绿 / 孔雀蓝**，黄昏 **金色反射带** 横贯画面 |
| 远山 | 3–5 层剪影，近山略深绿、远山青蓝，山脊可有金边 |
| 情绪 | 治愈、通透 — 对齐 [focus_work BGM](../../../SoundDesign/lake/day/focus_work.md) |

---

## 技术

| 项 | 值 |
|----|-----|
| 比例 | 16:9（3840×2160 交付） |
| Loop | 5 s / 10 s · 固定机位 · 禁 pan/zoom |
| 景深 | **全景深清晰**（近水—远山均可读） |
| 关联 SoundDesign | 钢琴 + 划船 + 鸟鸣 · 无雨层 |
