## 锚点（不变量）

| 字段 | 内容 |
|------|------|
| 相机位置 | **中心湖区 · 近水面平视**（船舷 / 低岸，眼高 ≈ 0.5–1 m） |
| 朝向 | 西南—西 **远眺群山** |
| 框景主体 | **平静湖面**（近景）→ 开阔水道 → **层叠远山与岛丘剪影** |
| 地标语义 | 千岛湖「湖中有岛、岛中有湖」— 水面视角望群峰 |
| 植被 | 远丘亚热带常绿阔叶林；近景无岛林占主体 |
| 与 CN-119 区别 | 黄山尖仍为 **俯瞰** 机位；CN-118 本变体为 **水面平视远眺** |
| 弃用机位 | ~~梅峰岛西观景台俯瞰~~ → 见 `CN-118_qiandao_dusk_v1.png` 归档 |

## 时段 · 黄昏（本变体）

| 项 | 描述 |
|----|------|
| 天光 | 西向 **暖金—琥珀** 余晖染远山脊线，东天 **蓝紫** 渐暗 |
| 湖面 | 碧玉绿 + **金色反射带**，占画面下 **1/2–2/3** |
| 远山 | 3–5 层 **青蓝剪影**，最远山脊可辨、不糊成一片 |
| 情绪 | 治愈、开阔、静谧；对齐 [focus_work BGM](../../../SoundDesign/lake/day/focus_work.md) |
| 禁 | 暴雨、雷、浓雾盖山、夜景灯光、大船占主体、航拍俯瞰 |
