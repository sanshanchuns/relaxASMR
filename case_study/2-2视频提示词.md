# 视频提示词（固定镜头筛选）

来源：`case_study/2-2视频提示词.mp4`（TapNow 第四节 · Seedance 2.0 Fast）。  
全片旁白：`2-2视频提示词.旁白.txt` / `.srt`。  
手册：`aigc/Seedance2.0手册.md`。

课里公式仍是 **主体 · 动作 · 效果 · 节奏**。本管线只生成 **固定镜头**，下面只留能直接抄进 prompt 的部分；推 / 拉 / 摇 / 移 / 手持 / 切镜头全文见旁白，不写入手册可抄块。

AIGC 三档送模正文固定四段（断言并进【约束】）。构图硬规则：必须有纵深三层，可与参考图不同，但不能缺。有参考图时先写：参考原图纹理、色调与雨夜氛围，严格执行以下约束。

```
【画面】固定机位 + 景别 + 写实浅景深；前景/中景/远景双标注
【光影】基调 + 光源位置冷暖 + 谁被照亮 + 无溢光
【动态】雨丝 + 叶面流水 + 植物轻微摆动
【约束】…
```

即梦确认：专业词「前景/中景/远景」比「近处/远处」准；双标注最稳。镜头景别 ≠ 纵深中景。

小雨档示例（海芋 + 藤蔓 + 木架）：

```
【画面】固定机位中景，写实雨夜温室绿植，浅景深，不裁切主体。前景（近处深色阔叶，画面右侧约三分之一）重虚，只见湿润高光，纹理不清；中景（画面中央海芋阔叶、黄白叶柄与三簇鲜红小球花，右侧暖色木架一角）唯一清晰，叶面雨湿、叶脉与缘滴可见；远景（左侧垂藤，约左四分之一）薄雾中微虚
【光影】冷暗雨夜基调。右侧一点暖橙微光只照中景植物上半，其余自然暗、无溢光、无其它光源
【动态】细密竖向丝状雨匀速下落；水沿芋叶自然下滑；绿植轻微平滑摆动，约三秒一周期；雾气同步缓流。首尾帧位置与运动状态吻合
【约束】镜头全程固定，无运镜、无切镜、无慢动作。不要生成音乐。画面中没有任何人物或手部。中景海芋为唯一清晰层。前景阔叶呈虚化剪影。海芋叶片仅受单滴雨点敲击微动，无剧烈晃动。叶片及木架表面仅形成反光水膜，没有流动水柱。
```

## 1. 动作 = 台词 · 肢体 · 情绪

情绪 AI 不一定懂，要转成**看得见的台词和肢体**。同一句「打招呼」，三种性格写成三种动作。全部 **固定镜头**。

**腼腆**

```
机器人像害羞的小姑娘一样扭捏地站着，双脚内八，膝盖微微并拢，肩膀缩起，双手贴在身前。它先低头躲开镜头，轻轻晃一下身体，犹豫后慢慢转头看向镜头，在胸前小幅挥手打招呼，随后立刻收回手，显得非常羞涩扭捏。固定镜头
```

**性格外向**

```
机器人右脚往画面左边迈了一步，同时兴奋地对镜头大幅连续挥手打招呼，固定镜头
```

**没有活力**

```
红色机器人略微弯腰，肩膀下垂，头低着，费力地抬起右手，对着镜头小幅挥手两下。动作沉重、僵硬，像电量不足一样疲惫。固定镜头
```

| 层 | 腼腆 | 外向 | 没有活力 |
|---|---|---|---|
| 肢体站姿 | 内八、并膝、缩肩、手贴身前 | 右脚向画面左迈一步 | 略微弯腰、肩下垂、头低着 |
| 打招呼 | 胸前小幅挥手，立刻收回 | 大幅连续挥手 | 费力抬右手，小幅挥两下 |
| 过程 | 低头躲开 → 轻晃 → 犹豫转头 | 迈步与挥手同时 | 沉重、僵硬 |
| 台词 | （无） | （无） | （无） |

带台词的开心版（课里「把动作写复杂」）：

```
红色机器人用机器人的语音说："你好，我是Tim，你喜欢这套AI影像课程吗？"它对着镜头打招呼，显得很开心。固定镜头
```

雨 ASMR：不写人物台词；同一套办法——不要写「宁静/治愈」，写成砸叶、溅花、水珠滚落。

## 2. 多主体：写清谁在做什么

画面里机器人 + 白马时，每个主体单独写动作：

```
红色机器人用机器人的语音说："你好，我是Tim，你喜欢这套AI影像课程吗？"它对着镜头打招呼，显得很开心。让画面中的白马站在地面上，缓慢抬起前蹄用后腿站立，仰天嘶鸣。固定镜头
```

结构：`主体A …。让画面中的主体B …。固定镜头`

## 3. 效果（固定镜头）

效果 = 镜头 · 环境 · 光影 · 速度 · 声音。本管线镜头只留 **固定镜头**。主体不动时，靠其余四项养活画面。

**镜头**

```
固定镜头
```

课里对照：三脚架 = 画面一动也不动。不要写推拉摇移、肩扛手持。

**焦点（背景模糊，xxx 清晰）**

```
背景变模糊，焦点在叶片上
一开始拳头是模糊的，焦点给到拳头，拳头变成清晰的
```

大白话即可，不必写 F2.8。光学虚化再加「浅景深」，不要写成环境「朦胧」。

**环境 / 光影（机位不动，场景在变）**

- 天气：晴天变成阴天下雨  
- 光影/时间：白天、黄昏、夜晚交替；夏→秋→冬→春  
- 可叠加：无音乐 + 一镜到底 + 主体始终在画面中央  

课里「主体冻结、效果养活」的完整固定镜头例（雨 ASMR 不要爆炸/闪电，可抄结构：天气、光影、时间、无音乐、主体静止）：

```
无音乐，连续一镜到底，全程固定镜头，机器人始终站在画面中央，开始完全静止，直到结尾挣脱。

节拍1：城市大楼各处突然发生爆炸，火光四射，冲击波扩散，玻璃碎片飞向空中，前景也有火光。画面进入慢镜头，碎玻璃在空中缓慢旋转，大楼部分坍塌。烟尘缓缓扩散。

节拍2：镜头不切换，场景进入废弃城市的快速延时变化，保持前面建筑爆炸后部分坍塌的状态。整座城市早已荒废多年，街道空无一人，没有行人，没有车辆，没有街灯亮起，也没有任何生活活动。时间迅速流逝，白天、黄昏、夜晚不断交替，天气从晴天变成阴天、下雨、起雾，再转晴，季节从夏季变成秋季、冬季再到春季。与此同时，墙面、街道裂缝和窗框中快速长出藤蔓、青苔和植物。植物不断蔓延、堆叠和增生，逐渐爬满所有大楼的外立面，地面上也从树苗开始长出了一颗颗大树，让整座城市变成被自然吞没的废墟遗迹。

节拍3：变速镜头。植物从地面裂缝、墙面和周围废墟中自然生长出来，藤蔓、枝叶和根须沿着机器人的双腿、腰部、身体和肩膀不规则地向上攀附和缠绕，层层蔓延，将机器人逐渐覆盖。机器人保持一动不动，双眼突然亮起强烈红光。短暂停顿后，机器人猛然挺身，肩膀和双臂同时向外一震，缠绕身体的所有藤蔓、根须和青苔在同一瞬间全部绷断并向四周弹飞，露出机器人的本体。挣脱发生得非常干脆、利落，没有拖泥带水。藤蔓断裂和弹飞的瞬间，画面立刻变成慢动作，碎叶、断裂藤蔓、根须和灰尘向四周缓慢扩散，突出机器人苏醒后的爆发力。

全程保持固定机位和同一构图，不切镜头，机器人主体保持完全静止直到最后一刻，通过慢动作、延时和变速镜头，表现爆炸的冲击感、时间的流逝感，以及机器人最终苏醒挣脱的爆发感。
```

**速度**：慢镜头 / 快镜头 / 变速 / 延时。雨 ASMR 慎用（会毁 loop 质感）。

**声音**

```
无音乐
不要生成音乐
```

每段 AI 各配各的会乱；画面完成后再配统一音乐。音效可写画外：`远处有汽车的喇叭声`。

## 4. 节奏：只要景别

课里节奏本意是切镜头。本管线 **不切、不推拉**，景别只用来定构图（镜头离主体多近）：

| 景别 | 离主体 |
|---|---|
| 大远景 | 最远，环境为主 |
| 远景 | |
| 全景 | 全身 + 环境 |
| 中景 | |
| 近景 | |
| 特写 | 局部（脸、手、叶） |
| 超大特写 | 最近 |

固定镜头 + 景别：

```
全景，固定镜头
特写，焦点在叶片上，背景变模糊，固定镜头
大远景，固定镜头
```

## 5. 四视图当细节参考（可选，锁外形）

T2V 角色每次长不一样。先图生一张锁定外形：

```
生成这台红色机器人的正面、侧面、正侧面、背面，四个角度放在一张图上，一字排开，纯白色背景
```

可再出一张脸部特写。视频提示词里写 `细节参考@图片1`（当前 AIGC Tab 没有节点，就把四视图当参考图 / 把角度写进 prompt）。
