# 磬入定 / 出定 · Suno / ElevenLabs 提示词

结构：开头一声**磬**入定 → 中间时有时无的**琵琶/中阮**与**颂钵** → 结尾一声**磬**出定。  
产线（入定/住定/出定怎么用在成片上）：`instructions/坐禅ASMR.md`。  
英文提示词生成更稳。不要写：治愈、史诗、电影感、人声梵唱、鼓、完整琵琶曲。

Suno Advanced 勾了 Instrumental 就只吃 **Styles**。`Zen / temple / meditation` 极易变成竹笛 BGM，Styles 里先写三种乐器再写 `no flute`。要卡准「开头磬、结尾磬」，改用 Prompt 模式或 ElevenLabs 三层。

---

## Suno（Advanced · v4.5）

勾了 **Instrumental** 后，Lyrics 会被锁死，只剩 **Styles** 生效。把占位词（metalcore、thumping bass 之类）全部删掉，只贴下面这一段。

**Styles**（整段复制）

```
qing bell, singing bowl, pipa, sparse ritual cue, one high bronze ding, low hollow bronze drone, faint rim rubbing, two or three quiet plucked lute notes, long silence, no melody, no dizi, no xiao, no bamboo flute, no woodwind, no flute, no guzheng, no piano, no drums, no vocals, no orchestra, not background music
```

滑块：**Style Influence 80%**（跟 Styles，少自己补笛），**Weirdness 60%**。先出短的，配器对了再 Extend。

若要卡「开头一声磬、结尾一声磬」，把 Lyrics 模式从 **Instrumental** 改成 **Prompt**，Styles 仍用上面这段，Lyrics 再贴：

```
[Intro] one qing bell ding, then silence
[Middle] singing bowl drone, occasional distant pipa, long rests, no flute
[Outro] one qing bell ding, silence
```

## ElevenLabs：三层音效（更稳）

Sound Effects 单条很难同时管好「首尾磬 + 中间时有时无」。先出素材，再排时间轴。

### 1. 磬（入定 / 出定共用）

时长 6–8 秒，`prompt_influence` 0.5–0.7。入定放第 0 秒，出定放到结束前，两条用同一条素材。

```
A single small Buddhist qing bell struck once, bright high metallic ding, clear and thin, long shimmering decay in a quiet temple hall, no other instruments, no singing bowl, no voice
```

### 2. 颂钵（中间垫底，可 loop）

时长 22–30 秒，loop 开。磬响完再淡入，出定磬前再淡出，避免盖过「叮」。

```
Deep hollow Tibetan singing bowl drone, low sustained hum with faint circling friction on the rim, slow beating overtones, empty temple resonance, no melody, no bell ding, no percussion, seamless ambient bed
```

### 3. 琵琶（时有时无）

时长 10–15 秒。多抽几条，中间随机丢 1–2 次，中间留大段静音。

```
Very sparse distant Chinese pipa, two or three quiet plucked harmonics and one slow slide, lots of silence between notes, dry zen atmosphere, no rhythm, no drums, no singing, far in the mix
```

## ElevenLabs 音乐模型（整段）

整段模型同样容易把结构打散。要卡入定/出定，仍建议用上面的三层叠。

```
Quiet Buddhist meditation cue. Opens with one bright qing bell strike. Then a low singing-bowl drone with faint rim friction. Sparse distant pipa notes that come and go. Ends with one identical qing bell. No vocals, no drums, no orchestra.
```
